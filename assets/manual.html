A-X-M · Ally XMB Menu

A PS3-style cross-media bar for the ROG Xbox Ally and any Windows handheld or PC. This page opens inside the menu's own browser: ▲▼ scroll, B closes it.

Left and right move between the columns: Users · Settings · Photo · Music · Video · Game · Network. Up and down move through a column. Y on almost anything opens the options sidebar on the right; Information in it shows the PS3-style details screen.

Users

Your profile (name and avatar), Turn Off System, Restart, Sleep and Exit to Desktop. The first boot asks for a name and offers avatars from the bundled set, SteamGridDB, or your own game icons.

Game

Every game found on every drive: Steam, Epic, Xbox / Game Pass, GOG-style folders and any folder you add in Settings. A plays. Y: Play, Lossless Scaling profile, Change Artwork (any SteamGridDB cover), Open Folder, Information.

Trophy Collection

Steam achievements per game (add your Steam Web API key in Settings › System › Trophies; your profile's game details must be public) and RetroAchievements (sign in once with your RA username and web API key).

Steam library, Saved Data, Game Data

Steam lists everything you own; A on an uninstalled game starts the install in the background and, with Hands-off Install on, confirms Steam's dialog for you. Saved Data Utility and Game Data Utility open save and install folders.

While a game is running

Press the Guide / PS button: Quit Game, Controller Settings, Turn Off the System, or back to the game.

Music

Browses your music folder-by-folder plus any drive's MUSIC folder. Y on a song: Information (tags, MusicBrainz artist, Cover Art Archive), Visualizer (eleven styles - ◀▶ switches on the stage), Add to Playlist, Shuffle, Copy to a drive. Create New Playlist sits at the top; Y on a playlist: Play, Edit, Copy, Delete, Information. An audio CD in a drive shows as a row with Import (MP3, AAC or Opus - pick the format in Settings › Audio).

Photo and Video

Pictures zoom (▲▼), rotate (Y), slideshow (A); Y in the list sets one as the wallpaper or shuffles a folder. Video plays MP4 with seek. Jellyfin in Video finds servers on the LAN (or type an address), signs in once, shows posters and backdrops, plays films and episodes, and downloads them to any drive. A DVD or Blu-ray in a drive shows as a row with Backup to MP4 (needs HandBrakeCLI, and MakeMKV for Blu-ray).

Copying: Y on songs, pictures and videos offers every drive's MUSIC / PHOTO / VIDEO folder, and "Copy to this PC" from a drive. New Folder… appears inside those drive folders.

Network

Web Browser opens pages inside the menu (D-pad scrolls and moves through history, Y reloads, B closes). Remote Play streams a PS4 or PS5 through chiaki-ng, fetched on first use; console registration and PSN sign-in happen in chiaki-ng itself. Online Instructions is this page.

Settings

  • Theme - monthly XMB colours or the PS3 colour picker, ribbon speed / width, visualizer style, welcome sparkle, wallpaper.
  • Display - fullscreen / windowed, menu resolution (720p to 4K, or auto), menu upscaling, refresh rate, FPS counter, hardware readout, battery percentage.
  • Audio - volumes, menu music (five loops or off), navigation sounds, shuffle, CD import format, music folders.
  • Network - connection status, Internet Connection on / off, Wi-Fi networks (join with a password on the on-screen keyboard), connection test, Media Server (Jellyfin) discovery, Bluetooth Register Device and Registered Device List.
  • System - System Name, Language, Date and Time, Power Save, Chat (menu audio output and microphone), Notifications, Predictive Text Dictionary, System Information, Controller, Trophies (Steam key, RetroAchievements sign-in), Steam options, game folders.

Tips

  • Keys and sign-ins live only in %APPDATA%\A-X-M\axm-settings.json; passwords are never stored.
  • A drive with PHOTO, VIDEO, MUSIC or GAME folders at its root gets its own rows; an unplugged one stays greyed until you forget it with Y.
  • Windows SmartScreen warns on first run because the build isn't signed - More info › Run anyway.
